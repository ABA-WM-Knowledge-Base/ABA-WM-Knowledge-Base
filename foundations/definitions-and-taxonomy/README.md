# Definitions and Taxonomy

## Retrieval metadata

**Relevant queries:** world-model definitions, historical lineages, classification axes, world foundation models, or world action models.

**Knowledge provided:** scoped terminology, family relationships, and invalid equivalences needed to compare mechanisms without collapsing distinct problem settings.

**Related pages:** [Problem formulation](../problem-formulation/README.md) owns mathematical contracts; [representations](../representations/README.md) and [learning objectives](../learning-objectives/README.md) own mechanism axes; [Cosmos3-Nano](../../models/cosmos3-nano/README.md) provides a model-specific instantiation.

## Canonical boundary

This subpart owns what a term denotes, which assumptions delimit it, and how model families relate along independent axes. It does not own detailed dynamics equations, representation mechanisms, learning algorithms, or model-specific product claims.
